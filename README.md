# Sea Service Log

A personal calendar for logging yacht sea service days (on board, sea, navigational watchkeeping, standby, yard and disembarked), with running totals and a signed PDF record.

**Open the app:** https://pelorus-capital-projects.github.io/sea-service-log/

## Login

The app opens behind a username and password, set up the first time you open it on each device (or brought across with a backup). **Forgot password?** on the login screen resets it with your recovery question. Only salted hashes of the password and answer are saved, never the words themselves.

## Your data

- Nothing you enter is sent anywhere. Days, profile and signature are saved in the browser you use, on that device only.
- Use **Crew Profile → Download backup** regularly, and **Upload backup** to move your log to another device or browser.
- This public copy contains no personal details or service record. Load your own with **Upload backup**.
